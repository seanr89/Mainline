# Mainline — Gemini Engineering Guidelines & Invariants

**Mainline** is a native-class macOS-style Git Workspace Manager built with **Rust**, **Tauri v2**, **React 18**, **TypeScript**, **Tailwind CSS**, **Zustand**, **TanStack Table v8 / Virtual v3**, and **tauri-specta**. It scans local workspace directories in sub-second time (500+ repos in `< 1,000ms`), monitors `.git/HEAD` and `.git/index` in real time, and executes safe, bounded batch Git operations with dirty-tree guardrails.

## 2. Non-Negotiable Engineering Invariants

### Rust Backend & Concurrency
1. **Non-Blocking Git Subprocesses**: Always execute `git` via `tokio::process::Command` with `.env("GIT_TERMINAL_PROMPT", "0")` so credential/SSH prompts never hang worker tasks.
2. **Bounded Worker Pools**:
   - Inspection (`inspect_workspace`): cap concurrency with `Arc::new(Semaphore::new(8))` (or `num_cpus`, bounded to avoid file-descriptor exhaustion).
   - Network/Batch Sync (`sync_repos`): cap concurrency with `Arc::new(Semaphore::new(4))`.
3. **Pruned Scanning**: Never traverse into `node_modules`, `target`, `.build`, `.venv`, `venv`, `bin`, `obj`, `Pods`, `vendor`, `dist`, `build`, or inside `.git`. When `include_submodules` is `false`, skip the parent directory once `.git` is discovered.
4. **Persistent Watcher Lifetime**: Never drop the `notify-debouncer-mini` `Debouncer` at the end of a setup function. Store the active watcher handle inside Tauri managed state (`WatcherState(Mutex<Option<...>>)`) so file watching remains alive for the active workspace root.
5. **Typed Errors**: Return `Result<T, AppError>` from all Tauri commands; never `.unwrap()` user-supplied paths or external Git subprocess outputs in command handlers.

### IPC & TypeScript Bindings (`tauri-specta`)
1. **Single Source of Truth**: Keep `src-tauri/Cargo.toml` aligned with `specta = "=2.0.0-rc.20"`, `specta-typescript = "=0.0.7"`, and `tauri-specta = "=2.0.0-rc.20"`.
2. **Safe Integer Export**: Configure `specta_typescript::Typescript::default().bigint(specta_typescript::BigIntExportBehavior::Number)` (or use `u32`/`f64` for counts/timestamps) so `usize`/`i64` fields in `RepoStatus` do not fail or panic during binding export.
3. **Register Every Command**: Every `#[tauri::command]` (`scan_workspace`, `refresh_repo`, `switch_branch`, `list_branches`, `sync_repos`, `watch_workspace`) must be included in `tauri_specta::collect_commands![...]` in `src-tauri/src/lib.rs`.
4. **Capabilities**: Keep `src-tauri/capabilities/default.json` minimal (`core:default`, `dialog:allow-open`, `store:default`). Only add permissions explicitly required by implemented features.

### Git Safety Guardrails (Core Product Promise)
1. **Never Bypass Dirty Checks**: Any batch sync, branch reset to `main`/`default_branch`, or checkout on a repository with `is_dirty == true` must intercept first and prompt the user via `DirtyConfirmModal` unless the user explicitly confirmed a strategy (`StashAndPull` or `HardResetAndPull`).
2. **Honest `SyncStrategy` Mapping**:
   - `PullFastForwardOnly` -> `git pull --ff-only` (only for clean repos, never miswired to stash)
   - `FetchOnly` -> `git fetch --all --prune`
   - `StashAndPull` -> `git stash push --include-untracked -m "Mainline auto-stash"`, `git pull --ff-only`, then `git stash pop` (reporting conflicts cleanly without silent data loss)
   - `HardResetAndPull` -> `git reset --hard HEAD`, optional `git clean -fd`, checkout target branch, and `git pull --ff-only` (only after explicit destructive confirmation)

### macOS-Style React Frontend
1. **Overlay Titlebar & Traffic Lights**: `tauri.conf.json` uses `"titleBarStyle": "Overlay"` and `"hiddenTitle": true`. `Toolbar.tsx` must reserve left padding (`pl-20`) for macOS window controls and attach `data-tauri-drag-region` to non-interactive header space.
2. **Virtualized Table Alignment**: `RepoTable.tsx` uses `@tanstack/react-table` v8 (`getCoreRowModel`, `getSortedRowModel` — **not** `getSortedCoreRowModel`) paired with `@tanstack/react-virtual` v3. Both `<thead>` rows and absolutely positioned `<tbody>` rows must use matching `flex` widths so columns stay aligned at 60 FPS.
3. **Event Listener Cleanup**: Always `unlisten()` Tauri events (`git-log`, `workspace-fs-change`) inside React `useEffect` cleanup functions.

## 4. Verification Gate Before Completing Any Phase

- **Rust changes**: Run `cargo check`, `cargo test`, and `cargo clippy -- -D warnings` inside `src-tauri/`.
- **Frontend changes**: Run `pnpm exec tsc --noEmit` and `pnpm build` at the repo root.
- **End-to-end / Benchmarks**: Use the `verification-matrix` skill (`.agents/skills/verification-matrix/SKILL.md`) to validate cold scan speed (`< 1,000ms` for 500 repos), virtualized scrolling, dirty-tree modals, and watcher debouncing.
