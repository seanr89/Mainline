# Changelog

All notable changes to **Mainline** will be documented in this file.

## [0.1.0] - 2026-11-21

### Features
- High-performance Rust + Tauri v2 + React macOS Git workspace manager
- Sub-second parallel workspace scanning with submodule toggle and live file-system watcher
- Virtualized repository table with branch switching, ahead/behind indicators, and dirty working-tree safety modal
- Batch Fetch, Fast-Forward Pull, and Reset to Main operations with real-time Git execution console
- Local macOS `Mainline.app` install and `update-app` Makefile workflow
